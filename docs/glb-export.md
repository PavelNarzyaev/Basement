# Экспорт подвала из Blender в GLB

Исходник: `models/basement/Basement.blend`.
Игровой файл: `public/models/basement/basement.glb`.

Откройте **File → Export → glTF 2.0** и выставьте настройки:

| Параметр | Значение | Зачем |
| --- | --- | --- |
| Format | glTF Binary (.glb) | Один файл с геометрией, материалами и текстурами |
| Include → Selected Objects | Выключено | Экспортировать весь подвал, включая лампы и зону |
| Include → Custom Properties | **Включено** | Сохраняет `collision = false` и маркеры `lightId` как glTF extras |
| Transform → +Y Up | Включено | Согласует оси Blender и Three.js |
| Data → Mesh → UVs | Включено | Сохраняет координаты текстур |
| Data → Mesh → Normals | Включено | Сохраняет нормали для освещения |
| Materials | Export | Сохраняет материалы и прозрачность |
| Vertex Colors | Material | Экспортирует цветовой атрибут, используемый материалом зоны |
| All Vertex Colors | Включено | Сохраняет RGBA атрибут `Color` с градиентом альфы |
| Animation | Выключено для подвала | Статической сцене анимации не нужны |
| Draco Compression | Выключено | В загрузчике проекта не настроен Draco-декодер |

Названия разделов могут отличаться между версиями Blender. Эти настройки проверены экспортом из Blender 5.2.1. Для модели игрока анимации должны быть включены.

## Зона приёмки

Сохраняйте отдельный объект `TrolleyCargoZone`, не объединяйте его с мешем подвала. В **Object Properties → Custom Properties** задайте `collision` как Boolean со значением **false**. Это свойство объекта, а не материала. Исключается также геометрия его дочерних объектов.

Отсутствие Rigid Body в Blender и прозрачный материал сами по себе не отключают игровые столкновения. Игра строит Octree по геометрии GLB. Теперь сборщик коллизий пропускает объекты с `collision = false`; имя `TrolleyCargoZone` также поддерживается для старых экспортов без extras. Зона не участвует в столкновениях игрока, ящиков, камеры и в поиске поверхности для размещения.

Зона имеет только четыре боковые грани. Материал использует **Surface Render Method: Blended**, выключенный **Backface Culling** и атрибут `Color`, подключённый к Base Color и Alpha узла Principled BSDF. Альфа вершин меняется от 0.28 внизу до 0 вверху. Процедурный градиент не требуется: RGBA сохраняется в GLB как `COLOR_0`, материал — с `alphaMode: BLEND` и `doubleSided: true`.

Высота зоны — 2 м, нижняя граница остаётся на настиле: Blender Z = 1.157307. Центр Blender: (-0.38983, 19.88941, 2.157307), локальные размеры: (3.24, 2.04, 2), поворот вокруг Z: 0.3104 радиан. Размеры мирового bounding box больше локальных из-за поворота.

В Three.js координаты переводятся как `(x, y, z) Blender → (x, z, -y)`. Логические границы подсчёта заданы отдельно в `src/scenes/contracts/trolleyCargoZone.ts`: при ручном перемещении или изменении размеров объекта синхронизируйте их.

После экспорта проверьте в игре, что игрок и переносимый ящик проходят через боковые стенки зоны, ящик ставится на настил, а счётчик увеличивается и уменьшается при размещении и подборе.
