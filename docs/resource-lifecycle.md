# Жизненный цикл ресурсов

Экземпляры приложения, сцены и бомбардировки используются для одного запуска: создание → загрузка → готовность → игра → освобождение. Игровой рестарт сбрасывает состояние готовых объектов и не загружает ассеты заново. После ошибки загрузки повторный запуск требует нового экземпляра приложения.

| Владелец | Ресурсы |
| --- | --- |
| `Application` | Renderer, ResizeObserver, интерфейс, ввод, игрок, мир коллизий; завершает сцену и бомбардировку |
| `BasementScene` | Статическая модель, исходная модель ящика и её экземпляры, свет, эффекты пыли и земли |
| `PlayerVisual` | Модель персонажа и AnimationMixer; останавливает анимации и передаёт модель disposer |
| `DustEffect`, `CeilingDebris` | Собственные геометрии, материалы и буферы GPU |
| `Bombardment` | AudioContext, источники звука, декодированные буферы, запросы звуков и подписка на видимость страницы |

`Object3DDisposer` освобождает геометрии, материалы, текстуры, ImageBitmap и скелеты. Общие ресурсы учитываются один раз за обход всех переданных корней. Сцена передаёт исходную модель ящика и экземпляры в одном вызове. Эффекты и игрок удаляют свои объекты из сцены до обхода её ресурсов.

Ошибка запуска останавливает кадры, отключает обработчики и освобождает все уже созданные ресурсы. На странице остаётся сообщение об ошибке; последующий `Application.dispose()` удаляет его. Повторное освобождение приложения, сцены и бомбардировки допускается.

Звуковые fetch-запросы отменяются через AbortSignal. Декодирование Web Audio не отменяется, поэтому после него проверяется сигнал; поздний буфер не сохраняется. Буферы публикуются только после успешной загрузки и проверки всего набора звуков.

В установленной Three.js 0.186.1 `GLTFLoader` наследует пустой `Loader.abort()`. Запросы моделей продолжаются до завершения. Сцена освобождает поздние модели, фабрика игрока проверяет сигнал до создания визуализации и освобождает отменённую модель, а приложение освобождает поздно возвращённого игрока. После завершения загрузочные callbacks не обновляют интерфейс. Ошибки отменённых загрузок не показываются как ошибки запуска.
