# Настройки в реальном времени

В режиме разработки доступна панель настроек, связанная с запущенной игрой. Параметры можно менять вручную или вместе с агентом через MCP: описать желаемое изменение, сразу оценить результат в игре и продолжить настройку без перезапуска сцены. Панель и агент работают с общим текущим состоянием.

Для начала запустите `npm run dev` и откройте адрес, указанный сервером. Панель находится в правом верхнем углу. Escape освобождает курсор после захвата мыши игрой; нажатие на заголовок сворачивает панель.

## Работа с агентом

В `.codex/config.toml` настроен MCP-сервер `basement_tuning`. Он подключается к уже работающему серверу разработки и не запускает игру самостоятельно. Через него агент может прочитать актуальные настройки, изменить предпросмотр, сохранить результат в проект или вернуть последние сохранённые значения.

Можно чередовать ручную настройку и запросы агенту. Перед изменением или сохранением агент читает текущее состояние через MCP. Состав доступных параметров определяется панелью и MCP-инструментами и может расширяться по мере развития проекта.

## Предпросмотр и сохранение

Изменения сначала применяются как предпросмотр и без явного запроса пользователя не сохраняются. Предпросмотр доступен открытым вкладкам игры и теряется при перезапуске сервера разработки.

Кнопка «Сохранить в проект» или соответствующий запрос агенту записывает текущие настройки в `src/tuning/contracts/tuningDefaults.json`. Сохранённые значения используются при следующих запусках и в production-сборке. «Сбросить» возвращает последние сохранённые значения.

Сохранение настроек не означает добавление изменений в staging, создание коммита или публикацию. Панель и MCP-интеграция предназначены для разработки; в production используются сохранённые настройки.
