# Basement

## Requirements

- Node.js 22.12 or later.
- npm (included with Node.js).

## Commands

- `npm ci` — Install the exact dependencies from `package-lock.json`.
- `npm run dev` — Start the development server and open the app in a browser.
- `npm run typecheck` — Check TypeScript types.
- `npm run build` — Check types and create a production build in `dist/`.
- `npm run preview` — Serve the production build locally and open it in a browser. Run `npm run build` first.
